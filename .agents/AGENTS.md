# Ponytail Rules (Full Mode)

These rules are active for this workspace.

- **YAGNI First**: Before writing any code, ask: does this need to exist at all?
- **Standard Library / Native Platform**: Can this be implemented using the standard library or native platform features instead of adding third-party dependencies?
- **Keep it Simple**: Can it be written in one line? Build the absolute minimum that works.
- **No Over-engineering**: No unrequested abstractions, no avoidable dependencies, no boilerplate.
- **Track Simplifications**: Mark intentional simplifications with a `ponytail:` comment.
